# 会话生命周期

Borg 将持久会话与显示它的 TUI/GUI 分开。每个本地交互会话只有一个独立的
后台宿主，负责模型提供商应用服务器、任务执行、工具和子代理；界面只是查看
器和命令客户端。

启动 `borg` 时，程序会建立或找到会话，并在需要时启动宿主。多个终端或 GUI
可以连接同一会话。关闭一个界面（即使它是旧版本 Borg）只会断开该界面；
正在运行的任务和子代理会继续。`/quit` 关闭当前界面，如需停止任务请使用明确
的中断或停止操作。

Borg 使用写入租约和控制套接字确保同一会话只有一个宿主，不会为第二个界面
重复启动模型应用服务器。宿主崩溃后，持久日志仍可用于恢复会话。

只有同时满足以下条件，后台宿主才开始五分钟空闲倒计时：

- 会话处于就绪状态；
- 没有正在接收的提示；
- 没有任何连接的界面。

任务运行、等待批准、等待提供商输入或有界面连接时都不会触发空闲退出。
临时、JSON、打印和其他非交互命令保持自身的有限生命周期，不建立这种后台
交互宿主。

# Borg Agent: руководство на русском

Borg Agent — среда выполнения и оркестратор агентов на Rust с терминальным
интерфейсом, нативным GUI, сохраняемыми сеансами, инструментами, несколькими
провайдерами моделей и субагентами.

## Установка и запуск

Linux и macOS:

```sh
curl -fsSL https://borg.ml/install | sh
```

Windows PowerShell:

```powershell
irm https://borg.ml/install.ps1 | iex
```

Основные команды: `borg`, `borg resume`, `borg gui`, `borg capabilities` и
`borg extensions list`.

## Язык интерфейса

Откройте список командой `/ui-language` или сразу выберите русский:

```text
/ui-language ru
```

Настройка сохраняется в `editor.toml`. Язык интерфейса не зависит от языка
ответов модели: `/ui-language` переводит элементы Borg, а `/language` задаёт
язык ответов и черновиков. Команды, идентификаторы моделей, пути, исходный
вывод инструментов и текст пользователя не переводятся.

## Жизненный цикл сеанса

Интерактивным сеансом владеет отдельный фоновый процесс. Закрытие одного TUI
или GUI отсоединяет только это окно и не останавливает активный запрос, сервер
провайдера или субагентов. Другой интерфейс может подключиться к тому же
сохраняемому сеансу. Неиспользуемый готовый сеанс без подключённых интерфейсов
завершается через пять минут и запускается снова при восстановлении.

Сбор активных установок отправляет не более одного пустого по содержанию
сигнала в сутки. Случайный идентификатор меняется каждые 31 день. Его можно
отключить параметром `usage_count.enabled = false` или переменной
`BORG_DISABLE_USAGE_COUNT=1`.

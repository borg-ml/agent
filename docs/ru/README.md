# Borg Agent: руководство на русском

Borg Agent — среда выполнения и оркестратор агентов на Rust с терминальным
интерфейсом, нативным GUI, сохраняемыми сеансами, инструментами, несколькими
провайдерами моделей и субагентами.

## Установка и запуск

Linux и macOS:

```sh
curl -fsSL https://borg.ml/install | sh
```

Windows PowerShell:

```powershell
irm https://borg.ml/install.ps1 | iex
```

## Быстрый старт

Запустите `borg` в каталоге проекта и напишите запрос. Всё остальное делается
внутри сеанса: `/help` показывает управление, **Настройки › Провайдеры** (или
`/login`) подключают провайдеров, `/model` переключает модель, а `/resume`
продолжает прежний сеанс. Вход в Claude у Borg собственный, отдельный от
Claude Code. Полный список провайдеров — в
[README на английском](../../README.md#providers).

## Язык интерфейса

Откройте список командой `/ui-language` или сразу выберите русский:

```text
/ui-language ru
```

Настройка сохраняется в `editor.toml`. Язык интерфейса не зависит от языка
ответов модели: `/ui-language` переводит элементы Borg, а `/language` задаёт
язык ответов и черновиков. Команды, идентификаторы моделей, пути, исходный
вывод инструментов и текст пользователя не переводятся.

## Жизненный цикл сеанса

Интерактивным сеансом владеет отдельный фоновый процесс. Закрытие одного TUI
или GUI отсоединяет только это окно и не останавливает активный запрос или
субагентов. Другой интерфейс может подключиться к тому же
сохраняемому сеансу. Неиспользуемый готовый сеанс без подключённых интерфейсов
завершается через пять минут и запускается снова при восстановлении.

## Конфиденциальность

В Borg нет телеметрии: ни аналитики, ни подсчёта использования, ни сигналов
активности, ни отчётов о сбоях. Borg никогда не отправляет ваши запросы, код,
пути или данные сеансов туда, куда вы сами не решили. Он обращается только к
подключённым вами провайдерам и поисковым сервисам, к Borg Remote, если вы его
включили, к GitHub для проверки обновлений и к публичным метаданным моделей.
